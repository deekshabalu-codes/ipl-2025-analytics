# IPL 2025 Match Outcome Predictor 🏏

This project uses machine learning to analyze IPL 2025 match data and predict match outcomes based on toss result and run difference.

## 🔧 Technologies
- Python
- Pandas, Seaborn, Matplotlib
- Scikit-learn

## 📊 Features
- Data cleaning and visualization
- Random forest classifier for prediction
- Feature importance analysis

## 📁 Files
- `ipl_2025.py` - Main analysis and ML code
- `ipl_2025_matches.csv` - Dataset
- `requirements.txt` - Required libraries

## 🧠 Predict a Match
Run the script and enter:
- Toss winner (0 or 1)
- Run difference

## 📌 How to Run
```bash
pip install -r requirements.txt
python ipl_2025.py
